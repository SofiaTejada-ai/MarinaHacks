MarinaHacks 4.0 - Coffee Website with Google Maps API
Developed during the MarinaHacks hackathon, this project is a coffee website that integrates the Google Maps API to help users find directions to their favorite coffee shops.

Project Overview
This project allows users to:
*Find nearby coffee shops using Google Maps API.
*Get directions to their preferred locations.
*Experience a seamless front-end interface with a Flask backend.

Tech Stack
Front-end: HTML, CSS
Back-end: Python, Flask
API: Google Maps API
JSON Handling: Flask's jsonify feature
Key Features & Challenges:
*Google Maps API Integration: Implemented dynamic location services.
* Flask Backend: Ensured smooth API communication and data handling.
*Bug Fixes & Debugging: Resolved compatibility issues between the latest Flask version and Google Maps API.
*Team Collaboration: Worked with a partner on UI design, API integration, and backend functionality.

How to Run the Project
1. Clone the repository:
git clone https://github.com/your-username/MarinaHacks4.0-main2.git
cd MarinaHacks4.0-main2

2. Set up a virtual environment (optional but recommended):
python -m venv env
source env/bin/activate  # On Windows: env\Scripts\activate

3.Install dependencies:
pip install -r requirements.txt

4. Run the Flask app:
python app.py

5. Open the website in your browser at:
http://127.0.0.1:5000/
